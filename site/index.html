Marginalia

Download Limits Privacy GitHub

A margin beside whatever you are reading.

You select a passage, or write a note, and the margin answers beside it. The source stays exactly as its author wrote it. Your notes stay on your computer.

A Chrome extension and a small helper program that runs on your own machine. MIT licensed.

Three promises

What the margin holds to.

  • The page is never rewritten.

    Marginalia does not edit, summarise over, or replace the source. Everything it adds sits in the margin, anchored to the exact words that prompted it. You can remove any of it, and the text underneath is unchanged.

  • Your notes are senior.

    Your note sits above the reply that answers it, in full ink. Replies are indented beneath, quoting the note version they answer. When you start writing, the passage your note is attached to freezes there. Reading on does not move it.

  • You see exactly what leaves your machine, and to whom.

    Selecting text sends nothing. Before any passage leaves a site for the first time, the margin shows you the exact text, the recipient and the scope, and asks once: this time, always on this site, or never on this site. A refusal stays refused.

Notes, highlights and threads are stored in a SQLite database on your computer and export as plain files.

The helper listens only on 127.0.0.1:43120. Read the privacy policy.

How it works

Three steps.

  1. Install the helper.

    One script installs dependencies, builds the local reader, and starts a small program at login. It holds your notes and is the only thing that talks to a model provider.

  2. Pair the extension once.

    The helper prints a six-digit code. It is valid for five minutes and can be used once. Enter it in the extension options and the two are paired. Pairing does not authorise anything to be sent.

  3. Read, select, keep or ask.

    Keep saves a highlight. Writing a note attaches it to the passage. Asking is a separate, deliberate action with its own consent step, and you can work entirely without it.

Node 24 is required to run the installer. Reading and note-taking need no account and no network.

Download

Install it.

Get the latest release

  1. Unzip the download.
  2. Open chrome://extensions in Chrome.
  3. Turn on Developer mode.
  4. Choose Load unpacked and select the extension folder.
  5. In the package folder, run .\scripts\install-helper.ps1 in PowerShell on Windows, or bash scripts/install-helper.sh on macOS or Linux.
  6. Read the six-digit pairing code from the helper output and enter it in the extension options.

If no release is listed yet, clone the repository and run the installer from marginalia-v2-package.

Both installers take -DryRun or --dry-run. To remove the login task or service, use -Uninstall or --uninstall. Uninstalling keeps your reading data.

Limits

What it does not do yet.

Asking the margin needs a local Codex runtime, and it is off by default.
You must authorise a Codex runtime on your own machine before the margin can ask anything. Until you do, reading, highlighting, notes and the library still work.
PDF support is deferred.
Marginalia reads web pages today. Reading PDFs in the same margin is planned work, not shipped work.
The native install is proven on Windows only.
The installer has macOS and Linux paths, and the test suite runs on all three systems in continuous integration. That is command-level evidence. The install itself has been accepted only on Windows.
It is not finished.
Parts of the product are built and tested but not yet wired end to end. The repository says which, in plain terms, and does not claim otherwise.

Claims on this page describe what runs at the current commit. Where evidence covers only one platform or one command, it says so.
