A personalized, agentic margin for the web.

Read a passage, keep your own note beside it, and ask for help when you need it. Your notes are senior to model replies. The page is never rewritten.

A Chrome MV3 extension and a local helper on 127.0.0.1. Reading data lives in local SQLite, with browser copies for recovery. MIT licensed.

Read now

Select a passage. Keep a highlight, write a note in your own words, or choose Ask. Notes stay attached to their source, with replies beneath them. Remember lets you keep vocabulary you choose; the app does not infer what you know.

Read it later

Park a passage or thread and return to a “You were here” resume line. Saved marks repaint when the page can be matched again. If the source has moved or the anchor is uncertain, the margin shows that state.

Retained local copies preserve source versions, notes and replies. Removing a thread does not erase every retained copy.

Your knowledge base

Kept passages, notes and replies collect in your local library with source attribution. Filter threads by state and export your work as plain files. Each page adds to a record you own.

How Ask works

Ask sends an approved passage and your chosen note to a Codex agent, with GPT-6 Astra available for deeper work. It can define a term, work an example or explain a passage step by step. Supported saved solvers can run again without another model turn.

Review the exact outgoing text, recipient and permission scope before dispatch. Choose this time, always on this site, or never on this site. Selecting, keeping and writing a note do not send a model request. Ask is a deliberate action; nothing sends on its own.

The Codex process starts locally; model inference runs on the provider’s service. The reader-authorized runtime has the limits below.

Library search and “Related saved passages” are available in the local library page. Code and automated tests support this claim; native browser acceptance has not been recorded.

Next

PDF reading and listening (“Hear it”) are next. Topics and reading paths across papers, sharing, connectors and Firefox are also planned.

Honest limits

Real asks use a reader-authorized mode where solver confinement is requested but not observed. The mode is off by default. No recorded real run is in the evidence folder yet. Read the runtime conditions.

Windows install is proven. macOS and Linux have command-level CI evidence. PDF is not supported yet.

The Astra build

Marginalia is built by Yash Gurbani, a team of one, with GPT-6 Astra via Codex and ChatGPT Pro. Claude Code supports integration and review. The Astra Challenge build used bounded tasks and review against the code; passing tests do not close the real-run or confinement gates.

The suite result is 961 tests: 955 pass, 0 fail, 6 skipped.

Install it.

Get the latest release

  1. Unzip the download.
  2. Open chrome://extensions in Chrome.
  3. Turn on Developer mode.
  4. Choose Load unpacked and select the extension folder.
  5. In the package folder, run .\scripts\install-helper.ps1 in PowerShell on Windows, or bash scripts/install-helper.sh on macOS or Linux.
  6. Read the six-digit pairing code from the helper output and enter it in the extension options.

If no release is listed yet, clone the repository and run the installer from marginalia-v2-package.

Both installers take -DryRun or --dry-run. To remove the login task or service, use -Uninstall or --uninstall. Uninstalling keeps your reading data.
