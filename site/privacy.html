Privacy

Last updated 18 September 2026.

Marginalia keeps your reading on your computer. Nothing you read, select, highlight or write is sent anywhere until you have looked at the exact passage, seen who would receive it, and said yes.

This page describes the program you install. It is written against the code, not against an intention.

There is no account, no sign-up and no analytics in the extension or the helper.

Storage

Where your work lives.

Your notes, highlights, threads and reading history are written to a SQLite database in a directory on your own machine. You can choose the directory with MARGINALIA_DATA_DIR. Nothing in that database is copied off your computer as part of ordinary use.

You can export the whole library as plain files at any time. Uninstalling the helper leaves your data in place.

Reading, highlighting and note-taking work with no network connection and no provider at all.

The helper

Everything stays on 127.0.0.1.

The helper listens only on the loopback address 127.0.0.1, by default on port 43120. It is not reachable from another machine. It checks the Host and Origin of every request and requires a pairing token that you granted and can revoke.

The extension holds that one token and nothing else. Provider credentials never enter the browser. Page scripts cannot read the token.

Pairing uses a six-digit code that the helper prints, valid for five minutes and usable once. Pairing connects the extension to the helper. It does not authorise anything to be sent to a provider.

A port number is not authentication. The pairing token is, and you can revoke it from the extension options.

Sending

Nothing leaves without your approval.

Selecting text sends nothing. Writing a note sends nothing. Saving and searching your own library sends nothing.

Asking the margin for help is a separate action. Before the first passage from a site is sent, the margin shows you:

  • the exact text that would go, including any notes you chose to include;
  • the recipient, named as the actual provider and runtime that would receive it;
  • the scope of the permission you are being asked for.

You then choose: this time, always on this site, or never on this site. A refusal persists and can be changed later from settings. On a site you have excluded, the margin does not offer an action that would fail.

Editing the request after the preview invalidates it. The frozen preview is what is sent, or nothing is.

The helper writes a record of every outgoing request before it dispatches and again after the outcome. That record is written by the helper, not by a model. If an outcome is unknown, the margin says it is unknown rather than claiming the request was not sent.

Asking uses a Codex runtime that starts on your computer, but the model inference itself happens on the provider's service. A local process is not local inference, and the consent preview names the real recipient.

Automatic work

Nothing runs on its own by default.

Asking the margin needs an authorised local Codex runtime and is off until you turn it on. Automatic definitions are a separate setting, also off by default. A site permission you granted for one thing does not switch on another.

Fetching pages from the web is a second, narrower permission, asked per site. When the helper fetches a page for you it records what it fetched. If it cannot establish that the record is complete, it labels the record incomplete instead of implying it is whole.

Closed sessions are meant to run with no network access. That confinement has not yet been independently confirmed, and this page will not claim it has.

Clicking an ordinary link in a page is your browser doing its normal job. It is not Marginalia fetching anything.

This website

The page you are reading.

This site is static HTML with its styles written inline. It sets no cookies, loads no fonts, scripts, images or stylesheets from other servers, and contains no analytics or advertising.

It is served by GitHub Pages. GitHub receives the ordinary request information any web server receives, such as your IP address, and handles it under GitHub's own privacy statement. Marginalia collects nothing from this page.

If you follow a link from here to GitHub, you are on GitHub's site and their terms apply.

Changes

If this changes.

This policy describes the code at the current commit. When the behaviour changes, this page changes with it, and the history is in the repository where you can read the difference.

Questions and corrections belong in the repository issues.
