# Marginalia demo script

Length: about two minutes. Recorded, with voice-over. Page: https://openai.com/index/navier-stokes-solution/

Button names below come from the code at `main`. If a control looks different on your screen, say what you see and keep going. Change any narration line into your own words; the facts in it are checked.

## Before you record

1. Start the helper with `npm start` in `marginalia-v2-package`. Keep the terminal off screen. The pairing code must never appear in the recording.
2. Load the unpacked extension and pair it in the margin's Settings. Do this before you press record.
3. Open the Navier-Stokes page. Remove any earlier marks on it so the margin starts quiet.
4. Decide which ending you will record. Try a real Ask once, off camera. If a reply comes back, record ending A. If it fails, record ending B and send me the error line.
5. Capture at 1600x1000 or larger, browser only. Hide bookmarks and other tabs.

## Ending A: the real Ask works

| Time | On screen | Say | Do |
|---|---|---|---|
| 1:20 to 1:40 | Approve the send. The reply arrives under your note. | "I approve it, and a Codex agent running GPT-6 Astra answers beneath my note. The reply can define a term, work an example, or explain step by step. My note stays senior." | Choose "this time". Wait for the reply. Scroll it once. |

If the reply takes longer than ten seconds, cut the wait in the edit. Do not speed up the footage of the reply itself.

## Ending B: the real Ask is not ready

| Time | On screen | Say | Do |
|---|---|---|---|
| 1:20 to 1:40 | The review screen, then close it without sending. The note and highlight remain. | "This build is an alpha. The ask path is built and reviewed, and I have not recorded a live provider run yet, so I stop here. Reading, notes, parking and the library all work without any model." | Close the question. Show the note still in place. |

Ending B is a fine demo. It shows the consent step, which is the part other tools skip.

## The 45-second cut

Use these beats in order: margin opens (0:10), select a passage (0:22), write a note (0:40), the review screen (hold three seconds), the library (1:40), end card. Open with the category line as on-screen text.

## Never on screen

- The pairing code, the helper terminal, or any path under your user folder.
- A reply you did not receive live. Fixture replies are test material only.
- PDF reading or "Hear it". Both are planned, and the margin labels them unavailable.
- Any request for upvotes.
