## Requirements disposition

| Requirement | Disposition |
|---|---|
| Separate the reader's claim from dated support | Implemented. Each entry keeps `claim` and `support` distinct; the transform never merges them. |
| Abstain without attributable support | Implemented. `verdict: insufficient` when no entry resolves to an observed fetch; the evidence headline is withheld. |
| A URL or model citation is not a fetched source | Implemented. A `fetched:true` entry with no matching observed record is neutralized to `unsupported-fetch-claim` and flagged. |
| Each substantive support resolves to a real host retrieval record | Implemented. `observed-fetch` binds the exact `FetchedResourceRecord` (finalUrl, sha256, fetchedAt, outcome). |
| Dates identify what is known and unknown | Implemented. `dates.claimedSourceDate` is model-declared and marked unverified; `dates.retrievalDate` is the host-observed fetch date, or null. |
| Closed sessions perform no retrieval | Implemented. A closed session with observed records is `refused`; a fetch claim in a closed session is `unsupported`. |
| Do not accept incomplete logs as complete | Implemented. `retrievalComplete:false` downgrades a real fetch to `unresolved` and withholds the headline. |
| Preserve source/consulted identity and completeness truth | Implemented. `boundSourceVersion`, `retrievalComplete`, and per-entry records are carried through. Stale source binding is detected. |
| Do not weaken SSRF/redirect limits or fabricate confinement | Held. The transform performs no IO and makes no confinement claim; the broker's limits are untouched. |
| Explain missing/insufficient/partial evidence calmly | Implemented. Per-entry `notes` and `reason` state the outcome plainly. |

## Public interface (for T06 Pro integration)

```ts
reconcileEvidence(reply: CandidateReply, observations: EvidenceObservations): EvidenceAssessment
```

`observations` is built by the host from records it already owns:
- `sessionScope` from the consent scope of the job.
- `retrievalComplete` from `EgressRecord.retrievalComplete`.
- `observed` from `EgressRecord.fetched` (`FetchedResourceRecord[]`).
- `boundSourceVersion` from `FrozenJobContext.sourceVersionId` + `sourceHash`.
- `currentSourceVersion` when the reply is re-checked against a newer capture.

Required wiring (T06 owns the change): after a validated evidence reply, assemble `observations`
from the attempt's egress record and call `reconcileEvidence`; store the `EvidenceAssessment`
alongside the host check report; expose `verdict`, `headline` and per-entry `attribution` to the
renderer so the citation authority line reflects host truth instead of the current author-only
string in `renderer/index.ts` (`case 'citations'`).
