## Host integration contract and limits

T06 must atomically reject duplicate dispatch claims and stale revisions, own the per-provider-thread predecessor/lease, persist user cancellation before calling the runner, and refuse final output behind a durable cancel/grant fence. The hook can return its canonical persisted handle/revision; production integration must reconcile canonical state rather than treating the test-only void callback as transactional proof. Restored handles come from the host store, never page/model data. Each `jobId` passed here must uniquely identify one execution attempt. `validateOutput` receives the handle so recovery can load the original schema and host-check context; it may receive no in-memory request after restart.
