## Question
A recovery report claimed the "You were here" line was delivered; the source had none. From now on, how are derived receipts reconciled: does a receipt count without a test or an evidence file?


## Fable's recommendation
No. A receipt without a test name or an evidence path is a claim, and the map records it as unverified. Fable applies this to E14 (the Pro review) and to every worker report.
