# ADR-0001 — The agent layer never writes to the source layer

**Status:** accepted 2026-09-04
**Context:** Bridge reshapes a document around the reader using an agent. The obvious design
lets the agent rewrite text (simplify, summarize in place, adjust vocabulary). Yash's ethos for
every reading/writing tool: AI-generated text is never mixed with human/source text;
generation assists in a separate layer.
**Decision:** Three layers (source / reader / agent). The page registers no WebMCP tool that
mutates the source layer. Compactify is a stub with a reason; vocabulary adaptation is a gloss;
summaries are annotations. Stub text is generated by the page from heading+reason, not by the
agent.
**Consequences:** Gives up in-place rewriting forever. Every agent artifact is attributed,
reasoned, removable; a "Source only" toggle always shows the untouched document. Enforced by
tool absence, not by prompt — cannot be argued around by the agent.
**Alternatives rejected:** (a) rewrite-with-diff (still mixes; readers stop noticing the diff);
(b) prompt-level rule (erodes; see Feynman drift post-mortem).
